Requirements (eXtreme Design scoping)

eXtreme Design (XD) builds an ontology in small iterations. Each iteration takes one user story, turns it into competency questions (CQs), finds the ontology design pattern (ODP) that answers them, specialises that pattern, and tests the result against the CQs before the next iteration starts. Each iteration here ends in a release with its own semantic version.

User stories

Story As a... I want to... so that... Iteration
S1 pizzeria owner describe what each pizza on my menu is made of - its base and toppings customers can see the ingredients 1 (v0.2.0)
S2 customer know which pizzas suit a vegetarian diet and how hot each one is I can choose quickly 2 (v0.3.0)
S3 pizzeria owner give every pizza on the menu a price in a currency the menu can be printed and compared 3 (v0.4.0)

Contextual statements

  • A pizza has exactly one kind of base and one or more toppings.
  • Toppings are grouped as cheese, meat, vegetable and fruit toppings; some are spicy.
  • A menu item is a particular pizza with its own base, toppings, diet category, spiciness level and price.

Reasoning requirements

  • SpicyPizza is defined, not asserted: any pizza with at least one spicy topping. The reasoner must place Diavola under it, because spicy salami is a spicy topping.
  • CheesyPizza likewise: any pizza with at least one cheese topping.
  • Everything stays in OWL 2 EL, so ELK - the reasoner the in-process build uses - classifies it, and in OWL 2 DL, which validate_profile checks.

Patterns chosen

Each chosen in OntoBoard → ROBOT → Pattern library... by searching for the CQ's words. The library answers with patterns whose own competency questions match. All three are sound: the library's reasoner check (patterns/soundness.tsv in OntoBoard) found each consistent with no unsatisfiable class.

Iteration Pattern (library id) Its own CQs Specialised as
1 Componency (componency) What are the components of this entity? What is this entity a component of? Pizza, PizzaBase, PizzaTopping ⊑ Object; hasBase, hasTopping ⊑ hasComponent
2 Classification (classification) What concept classifies this entity? What entities are classified by this concept? DietCategory, SpicinessLevel ⊑ Concept; menu items isClassifiedBy vegetarian, mild, hot
3 Price (price) How much does a given item cost, and in which currency? MenuPrice ⊑ Price; euro a Currency; hasPrice, hasCurrency, hasValue

Source: the ontology design patterns are from the ODP portal (ontologydesignpatterns.org), bundled with OntoBoard; each import keeps the pattern's own IRIs.
